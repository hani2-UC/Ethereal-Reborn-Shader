# Ethereal Reborn Shader 1.0.0

Minecraft Java Edition向けに、見た目の変化を優先して一から組み直した幻想系シェーダーパックです。

## 主な表現

- 太陽・月によるリアルタイム影とソフトシャドウ
- 元の水位を越えない立体波、フレネル反射、スクリーンスペース反射
- 元の水テクスチャを使わない、透明な屈折・深度吸収・浅瀬の光模様
- 深さに応じた透明感とシアン色の吸収表現
- 暗いディメンションでも現れる星空、星雲、動くオーロラ
- SSAOによる接地感
- 多段ブルームと発光色のにじみ
- 映画調のトーンマッピング、色調補正、ビネット
- 草・葉などの揺れ

## 導入方法

`Ethereal-Reborn-1.0.0.zip` を展開せず、使用中のMinecraftインスタンスの `shaderpacks` フォルダへ入れてください。

IrisまたはOptiFineのシェーダー選択画面から `Ethereal Reborn 1.0.0` を選択します。最初はプロファイル `CINEMATIC` が推奨です。

## プロファイル

- `BALANCED`: SSR 24ステップ、影・SSAO・ブルームを抑えた設定
- `CINEMATIC`: SSR 48ステップ、強めのブルームと幻想表現（既定）
- `EXTREME`: SSR 64ステップ、反射・SSAO・オーロラを最大寄りに設定

このパックの水面反射は画面内の地形を反射する方式です。画面外の景色は、空の反射で補完されます。
